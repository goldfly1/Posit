```
  → model reads C# interface, writes class implementing it
  → StaticChecker pre-flight: no Dafny types, has namespace/class, no markdown fences
  → Build correction loop: dotnet build temp project → feed CS errors → retry (max 4)
  → WiringGenerator: deterministic Wire.cs from scanned signatures + connections
  → Falls back to ModelWiringGenerator (LLM) if deterministic output is empty

QA (deepseek-v4-flash:cloud)
  → model generates 3-6 test data files (valid, edge, invalid, empty inputs)
  → deserializer handles bare array or wrapped object
  → Docker harness: dotnet build + run + compare output (fuzzy match)
  → WireFixer correction loop on build/test failures (6 retries max)
  → Fallback: deterministic GenerateTestData heuristic if AI generation fails
```
