## What Doesn't Work (Monday's 4 Items)

### 1. Cut-outs don't chain (type chain break)

`ValidateRows` returns `_IValidationResult` (verdict). `SerializeToJson` expects
`ISeq<ISeq<ISeq<Rune>>>` (rows). The chain breaks.

**Fix:** Redesign cut-outs to pass data through. `ValidateRows` returns
`(rows, isValid)` — data rides alongside verdict. Rows continue down the chain.

**Files:** `patterns/cut-outs/row-validator.dfy`, re-verify with Z3, re-translate.

### 2. Two dimensionality conversions (wrap vs split)

`string → ISeq<ISeq<Rune>>`: wiring wraps whole string as 1-element. Should split
by newlines. `ISeq<Rune> → ISeq<ISeq<Rune>>`: same problem.

**Fix:** Stubs return the right shape. Use `ReadLines` (returns `string[]` = lines)
instead of `ReadFile` (returns `string` = whole file). The Dafny stub `ReadLines`
declares `returns (lines: seq<string>)` which maps to `ISeq<ISeq<Rune>>` — no
dimensionality upgrade needed. Update prompt to tell architect to use ReadLines.

**Files:** `src/Posit.Cli/Orchestration/PromptBuilder.cs`, `src/Posit.Phases/WiringGenerator.cs`
(remove wrap conversions or make them throw).

### 3. Post-Dafny type chain check

Scanner runs during Architecture — before real types exist. Need a type chain check
AFTER Dafny Implementation where real C# types are known.

**Fix:** New `TypeChainChecker.cs`. After Dafny translation, for each consecutive
pair of connections: check return type of step N is compatible with first param
of step N+1. If not, kick back to Architecture with the mismatch details.

**Files:** New `src/Posit.Phases/TypeChainChecker.cs`, update `PositOrchestrator.cs`.

### 4. Orchestrator doesn't need patternName

The orchestrator component (e.g. `CsvToJsonPipeline`) uses the `pipeline` pattern
but its body is dead code. Wire.cs has its own `Main` that calls other components
directly. The pipeline pattern is cosplay.

**Fix:** Scanner rule — a component with connections doesn't require `patternName`.
The connections are the spec. The wiring is the implementation.

**Files:** `src/Posit.Phases/ContractScanner.cs` (skip patternName check for
components with connections).
