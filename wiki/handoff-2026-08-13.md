### The Verdict: Bandaid Fest

The fixes are individually correct but structurally insufficient. Each pipeline run produces a different architecture with different method names, types, and connection patterns. Patching the wiring generator per-error doesn't scale — there are infinite ways the model can vary its output.

**Root cause: the wiring generator works from metadata (pattern signatures, connection specs) and never sees the actual translated C#.** Every mismatch is because metadata ≠ reality.

### The Real Fix (NOT YET DONE)

**Read-then-wire:** Read the actual translated C# files before generating Wire.cs. Extract real method signatures, parameter types, and return types from the compiled output. Generate calls against what's actually there.

This eliminates the entire class of "method name mismatch", "param count mismatch", "type incompatibility", and "void return" bugs at the root.
